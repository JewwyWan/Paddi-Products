# Paddi 产品与公开安装包

Paddi 包含四款独立安装的 Android 应用：整理试题的 **Paddle**、联系好友的 **Paddcht**、管理统一账号的 **Paddi Account**，以及提供 AI 对话的 **PaddLem**。

多数较新的安卓手机使用 **ARM64**。Paddle、Paddcht、Paddi Account 只提供 ARM64；PaddLem 另外提供 ARMv7、x86_64 和通用包。

Paddcht 0.8.2 支持用手机扫码确认电脑登录，手机和电脑可以同时在线。二维码登录需要在手机端明确核对电脑名称和六位数字。
